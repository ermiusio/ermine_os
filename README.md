# ermine_os
Ermine это минималистичный Live-дистрибутив на базе Debian для приватного серфинга и работы с криптой. Включает только Tor Browser с защитой от фингерпринтинга, Cake Wallet и i2pd. Всё лишнее удалено для уменьшения поверхности атак. Еще есть kill-switch, использует ротацию MAC, AppArmor и усиленное ядро. Нет persistent-хранилища, swap отключён.
